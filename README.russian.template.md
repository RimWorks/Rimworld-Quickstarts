# Quickstarts: сценарии быстрого запуска для разработки модов RimWorld

Пропустите меню и попадайте сразу в колонию, уже настроенную так, как вам нужно. Quickstarts заменяет кнопку quicktest в RimWorld вашими собственными сценариями: они пишутся на C# и запускаются из меню разработчика или флагом в командной строке. Без выбора сценария, без планеты, без перебора пешек, без выбора места высадки.

```csharp
public class TinyColony : AbstractQuickstart {
  public override TaggedString description => "One small map, three colonists, paused.";

  public override int mapSize => 50;

  public override void PrepareColonists(List<Pawn> pawns) {
    foreach (Pawn pawn in pawns) {
      pawn.playerSettings.hostilityResponse = HostilityResponseMode.Attack;
    }
  }
}
```

## Кому это нужно

Авторам модов. В обычной игре Quickstarts не добавляет ничего, так что подписываться есть смысл только если вы делаете или тестируете мод.

## Чем это отличается от обычного quicktest

Ванильная кнопка quicktest бросает вас на случайную карту со случайными колонистами, и ни то ни другое изменить нельзя. Каждый запуск это другая колония, так что проверить одно и то же дважды не получится.

Quickstarts вешает на ту же кнопку список всех быстрых запусков, которые объявили загруженные моды. Выбираете один и оказываетесь на карте, на паузе, с уже настроенной колонией.

Зафиксируйте зерно мира, и два запуска дадут одну и ту же планету, ту же клетку высадки и тех же колонистов. Сбой можно воспроизвести, а не ловить заново.

Каждый неабстрактный наследник появляется в списке сам. Добавить быстрый запуск значит написать класс и больше ничего.

## Что можно настроить до загрузки карты

Хуки срабатывают там, где это важно: до генерации, когда мир уже создан, когда сценарий закончил собственную настройку, и после появления колонистов. Задайте число пешек, завершите исследования, раздайте снаряжение или откройте ту панель, над которой работаете.

## Можно ли гонять это как smoke-тест в CI

Да, ради этого их и пишут. Запустите тот же сценарий с флагом проверки, и игра сверит свои утверждения с живой симуляцией, а затем выйдет с кодом успеха или провала. Пишется и JSON-отчёт, и JUnit XML, так что CI может отметить упавшее утверждение прямо в пулл-реквесте. Экран не нужен.

Красные ошибки в игровом логе по умолчанию роняют запуск, и именно это ловит сломанное взаимодействие модов. Таймаут по реальному времени останавливает зависший запуск и называет стадию, на которой он умер.

## Требования

RimWorld 1.5, 1.6 или 1.7, включённый режим разработчика и одна библиотека патчей. Подойдут и Harmony, и Concord. Если есть обе, Quickstarts выберет Concord.

## С чего начать

Подключите пакет RimWorks.Quickstarts.Ref, унаследуйтесь от AbstractQuickstart, и ваш быстрый запуск появится в списке. Чтобы поставлять его из мода, не навязывая эту зависимость игрокам, положите его в папку, закрытую через loadFolders.xml.

Исходный код и документация: https://github.com/RimWorks/Rimworld-Quickstarts
